# 纸间集市 Demo

解压后，直接用浏览器打开 index.html 即可体验。三个文件请保留在同一文件夹。

- index.html：页面和 SVG 基础元素
- style.css：视觉样式与动画
- app.js：集市场景、居民行为、聊天与互动

无需安装依赖或配置 API。字体在线加载，断网时使用系统字体。

本版本采用本地情境规则，并未接入大语言模型；刷新后互动记录重置。

可将三个文件放入 GitHub Pages 的发布目录，入口为 index.html。

v2：修复点击小人无反应；点击后弹出对话气泡并停下聊天；新增全屏模式（按钮或 F 键，Esc 退出）；整体质感与排版优化。
