# 纸间集市 · 梧桐镇

**在线体验**：https://dionysus23334.github.io/Agent-City-Demo/

一座手绘纸感的交互小镇。纯 HTML / CSS / JavaScript，无需安装依赖、后端或 API Key。

## 第四章 · 一张大地图，二十位邻居

- **连续大地图**：集市、花园、书屋、河岸由同一套街道相连。20 位居民一直存在于同一世界，跨区散步、找朋友和赴约都沿街步行。
- **新增 10 人**：露露（咖啡师）、陶陶（陶艺师）、陈叔（修车师傅）、小宁（学生）、温老师（退休教师）、乔乔（摄影师）、余伯（船夫）、松松（蜂农）、夏夏（裁缝）、白白（园艺志愿者）。每人都有个性、目标和邻里关系。
- **16 段故事 / 32 个选择**：保留原有故事，新增送花苗、蜂蜜咖啡合作、修自行车、合影与口述史。
- **镜头操作**：拖动、滚轮或按钮缩放、全镇总览、人物面板可以跟随居民。移除街区跳转按钮，以直接拖动地图为主。
- **事件流程**：参与者步行集合 → 到齐后选择 → 原子结算物资、关系与记忆。取消不扣物资，已完成事件不能重复结算。
- **互动与环境**：情境聊天、送苹果、跨街区散步、邀请朋友；晴雨黄昏、暂停、1× / 2× / 4×、全屏。
- **存档兼容**：沿用 v3 本地存档，保留物资、旧人物关系、记忆和已完成故事，自动补齐新居民。刷新后回到各自常驻街区，进行中的集合取消且不扣资源；不同浏览器不共享进度。

这是规则驱动的交互原型，不是已接入大语言模型的自主智能体系统。自由输入按情境关键词响应，不能承诺开放式推理。

## 使用

把所有源文件保留在同一目录，打开 `index.html` 即可。在线字体不可用时会回退至系统字体。拖动地图观察街道，点击居民或下方人物卡互动；卡片可以定位不在当前场景的居民。

点击「故事与事件」开始一段故事，等居民到齐再选择结果。支持暂停、1× / 2× / 4×，按钮或 F 键进入全屏，Esc 退出。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面及基础 SVG 元素 |
| `style.css` | 绘本样式、响应式布局、天气动画 |
| `visuals.js` | 连续地图与深度排序装饰 |
| `residents.js` | 居民人设、关系、场景导航点、故事内容 |
| `town-model.js` | 物资校验、单次结算、存档恢复 |
| `navigation.js` | 可行走区域、障碍检测、跨区寻路和随机落脚点 |
| `app.js` | 寻路、人物行为、对话、故事流程和界面 |
| `tests/simulation.test.cjs` | 事件结算与跨场景寻路回归检查 |

## 验证

有 Node.js 时运行 `node tests/simulation.test.cjs`。覆盖 20 位唯一居民、32 个选择、重复结算拦截、余额不足保护、存档恢复，以及 576 对全镇节点路径的可达性、逐帧移动距离约束和中途重新寻路。

浏览器检查：20 人同图、镜头总览/缩放、跨区合影事件集合与结算、人物交互与跟随。

## 发布

- `main`：源文件。
- `gh-pages`：GitHub Pages 发布分支，与本次验证通过的源文件同步。

两个分支根目录均包含 `index.html` 和所有依赖文件。更新源码后需要同步发布分支，才能更新线上页面。
