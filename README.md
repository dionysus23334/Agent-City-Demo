# 纸间集市 · 梧桐镇

**在线体验**：https://dionysus23334.github.io/Agent-City-Demo/

一座手绘纸感的交互小镇。纯 HTML / CSS / JavaScript，无需安装依赖、后端或 API Key。

## 第三章 · 四处风景，十位邻居

- **4 个独立场景**：河畔集市、共享花园、旧街书屋、河岸舞台，保留原版手绘风格、全屏与人物气泡。
- **10 位居民**：原有六人之外，加入书屋管理员阿序、木匠木生、街头乐手小悦和自然观察员糖糖。
- **12 段故事 / 24 个分支选择**：分享面包、共建花圃、转交旧信、河岸演出、修理长椅、露天读书会、阵雨避难、蝴蝶观察、苹果派合作、公共公告板、花园野餐、归家路灯。
- **完整事件流程**：选择故事 → 参与者跨场景到达并步行集合 → 对话 → 玩家选择 → 物资、关系、记忆和环境更新。集合期间可以取消，不消耗物资。事件只能结算一次。
- **居民互动**：情境聊天、计划/关系/记忆快捷问答、赠送苹果、散步邀请、邀请朋友见面。居民也会自主散步、换场景、相遇聊天。
- **公共物资**：公共基金、面包、苹果、种子和木料；消费前校验余额，不允许负数。邻里温度与人物关系有上限。
- **环境变化**：晴、雨、黄昏光景可切换；播种、野餐、演出、公告板、路灯等故事会改变相应场景。
- **本地存档**：完成的故事、物资、人物熟悉度、关系、最近记忆和手记保存在当前浏览器。进行中的集合不存档，刷新后取消且不扣资源。位置回到各自常驻场景。不同浏览器不共享进度。

这是规则驱动的交互原型，不是已接入大语言模型的自主智能体系统。自由输入按情境关键词响应，不能承诺开放式推理。

## 使用

把所有源文件保留在同一目录，打开 `index.html` 即可。在线字体不可用时会回退至系统字体。点击场景标签切换地点，点击居民或下方人物卡互动；卡片可以定位不在当前场景的居民。

点击「故事与事件」开始一段故事，等居民到齐再选择结果。支持暂停、1× / 2× / 4×，按钮或 F 键进入全屏，Esc 退出。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面及基础 SVG 元素 |
| `style.css` | 绘本样式、响应式布局、天气动画 |
| `visuals.js` | 四处场景与深度排序装饰 |
| `residents.js` | 居民人设、关系、场景导航点、故事内容 |
| `town-model.js` | 物资校验、单次结算、存档恢复 |
| `app.js` | 寻路、人物行为、对话、故事流程和界面 |
| `tests/simulation.test.cjs` | 事件结算与跨场景寻路回归检查 |

## 验证

有 Node.js 时运行 `node tests/simulation.test.cjs`。覆盖 24 个选择、重复结算拦截、余额不足时原子拒绝、存档恢复，以及 444 条场景内路径的可达性与碰撞检查。

浏览器验收覆盖花园事件集合与结算、刷新后的物资/记忆恢复、人物问答以及场景切换。

## 发布

- `main`：源文件。
- `gh-pages`：GitHub Pages 发布分支，与本次验证通过的源文件同步。

两个分支根目录均包含 `index.html` 和所有依赖文件。更新源码后需要同步发布分支，才能更新线上页面。
